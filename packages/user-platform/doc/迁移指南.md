# SCSS 优化迁移指南

## 📋 迁移概述

本次优化将原有的CSS文件重构为标准的SCSS架构，提供更好的可维护性和开发体验。

## 🗂️ 文件对照表

### 原始文件 → 新文件结构

| 原始文件               | 新文件位置                             | 说明                   |
| ---------------------- | -------------------------------------- | ---------------------- |
| `main.scss`            | `main.scss` + `abstracts/` + `themes/` | 拆分为基础样式和抽象层 |
| `home.scss`            | `pages/_home.scss`                     | 移至页面层             |
| `login_page.scss`      | `pages/_login.scss`                    | 移至页面层，重命名     |
| `post.scss`            | `pages/_post.scss`                     | 移至页面层             |
| `forum_interface.scss` | `pages/_forum.scss`                    | 移至页面层，重命名     |
| `knowledge_graph.scss` | `components/_knowledge-graph.scss`     | 移至组件层             |
| `tag_color.scss`       | `components/_tags.scss`                | 移至组件层，重命名     |
| `app.scss`             | `app.scss`                             | 新的主入口文件         |

### 新增文件

| 新文件                      | 作用             |
| --------------------------- | ---------------- |
| `abstracts/_variables.scss` | 统一的设计变量   |
| `abstracts/_mixins.scss`    | 可复用的样式混入 |
| `abstracts/_functions.scss` | SCSS计算函数     |
| `themes/_light.scss`        | 亮色主题变量     |
| `themes/_dark.scss`         | 暗色主题变量     |

## 🔄 迁移步骤

### 第一步：备份原文件

```bash
# 创建备份目录
mkdir assets/css/backup

# 备份原文件
cp assets/css/*.scss assets/css/backup/
```

### 第二步：更新导入语句

如果你的项目中有导入这些CSS文件的地方，需要更新：

**原来:**

```javascript
// 在 Nuxt 配置或组件中
import '~/assets/css/main.scss'
import '~/assets/css/home.scss'
import '~/assets/css/login_page.scss'
// ...其他文件
```

**现在:**

```javascript
// 只需要导入主文件
import '~/assets/css/app.scss'
```
